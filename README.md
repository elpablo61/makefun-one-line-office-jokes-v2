## The line

> At 4:58, Rudi stopped by my desk for 'one quick question', and at 6:12 he was still talking while the cleaner vacuumed around his feet.

One line, 135 characters. A single office moment: two exact clock times, one named
colleague, and a final image that lands the laugh in the last few words — no setup
that needs explaining.

## Run

```sh
node main.ts
```
